## 📌 Project Overview

OLA Ride Insights is an end-to-end data analytics project focused on analyzing ride-sharing data to understand booking trends, customer behavior, vehicle performance, revenue patterns, cancellations, and ratings.

The project uses SQL, Python, Power BI, and Streamlit to transform raw ride data into meaningful business insights.

## 🎯 Problem Statement

This project aims to analyze OLA ride data and provide insights that can support better operational efficiency, customer satisfaction, and data-driven business decisions.

## 📱 Streamlit Application

The application includes five analytical sections:

1. **Overall Analysis** – Booking trends and booking status.
2. **Vehicle Type Analysis** – Ride distance by vehicle type.
3. **Revenue Analysis** – Payment methods and customer booking value.
4. **Cancellation Analysis** – Customer and driver cancellation data.
5. **Ratings Analysis** – Driver and customer rating distributions.
