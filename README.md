# 🚕 OLA Ride Insights – Data Analytics Project

## 📌 Project Overview
OLA Ride Insights is an end-to-end data analytics project focused on analyzing ride booking data to identify business trends and performance insights.

This project uses Python, SQL, Power BI, and Streamlit to explore ride bookings, revenue, vehicle performance, cancellations, and customer and driver ratings.

## 🎯 Project Objectives
- Analyze overall ride booking trends.
- Identify the most popular vehicle types.
- Understand revenue by payment method.
- Analyze customer and driver cancellations.
- Evaluate customer and driver ratings.
- Present insights through interactive dashboards.

## 🛠️ Tools & Technologies
- Python
- Pandas
- MySQL
- SQL
- Power BI
- Streamlit
- Plotly

## 📊 Project Modules

### 1. Overall Analysis
- Ride volume trends over time
- Booking status breakdown

### 2. Vehicle Type Analysis
- Top 5 vehicle types by ride distance
- Average customer ratings by vehicle type

### 3. Revenue Analysis
- Revenue by payment method
- Top 5 customers by total booking value
- Ride distance distribution per day

### 4. Cancellation Analysis
- Customer cancellation analysis
- Driver cancellation analysis

### 5. Ratings Analysis
- Driver ratings distribution
- Customer ratings distribution
- Customer vs. driver ratings comparison

## ✨ Key Features
- SQL-based data analysis
- Interactive Power BI dashboards
- Streamlit web application
- Interactive filters
- Booking ID search
- Data visualizations using Plotly

## ▶️ How to Run the Project

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```
